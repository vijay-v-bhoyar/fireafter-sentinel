**Provider choice:** call NVIDIA Nemotron through Nebius Token Factory at runtime. Select an account-verified extraction model; evaluate Nano/Super candidates only if actually offered, measuring quality/cost before escalation. Store exact model ID and prompt/schema/config versions. A stronger model is a later measured extension. The current worker does not escalate; ambiguity stays held for human review. Confirm endpoint schema/tool behavior in a real authorized test. App frontend/database may remain on separate hosting.

**Source authority:** prefer primary issuer documents applicable to the exact incident/jurisdiction and interval. Domain allowlisting narrows discovery; it does not prove the page is current, complete, applicable or a revision of another page. Newer publication time alone does not override another issuer. Conflicting notices preserve both and require review. No document can supply missing burn severity through prose unless a separately validated measurement contract exists.

**Crawler boundary:** use fixed verified provider endpoints; never execute a returned/model-selected URL directly. Canonical registered URLs must pass strict HTTPS/host/path rules and reject credentials, IP literals, local/private hostnames and unsupported schemes before provider dispatch. Search results are candidates until admitted to the registry. Tavily performs its own retrieval; the app cannot claim to enforce or attest its hidden DNS/redirect hops. If final issuer/applicability/completeness cannot be established from returned content and reviewed provenance, hold the claim. No app-side arbitrary fetch/browser tool exists in this release. Any later direct-fetch adapter needs its own resolver/redirect/network controls and tests.

**Concrete adapter behavior:** Search uses fixed domain filters and max_results=5. Provider filters may include sibling hostnames: the adapter forwards only exact registered hostnames, records withheldResultCount, permits an empty discovery result after withholding all off-registry hits, still rejects duplicate admitted result sets, and charges the complete provider attempt. Search hits remain discovery candidates, not source admission. Query text is derived from the original operator-reviewed issuer/jurisdiction registry, never arbitrary user/model text, private notes or facility details. Extract uses registered URLs in one batch with full-content settings, no relevance query/chunk sampling, images disabled and bounded timeout. Examine both results and failed_results even for HTTP 200; require exactly accounted requested URLs, reject duplicates/unknown returned URLs, and retain request_id where supplied. Extracted text is the preserved source representation; do not invent original HTML bytes, HTTP status, publication date or complete redirect provenance. The current worker makes one Search and one Extract without transport retries. The four-request SQL ceiling is a reservation cap, not implemented retry behavior. Any later qualified retry must use an explicitly authorized new attempt within the original cumulative budget; an uncertain paid attempt never grants redispatch. **Temporal policy:** accept only source-supported publication/effective metadata; preserve null when absent. Date filters are retrieval hints. Freshly fetched old content stays old. Rechecking identical content adds a retrieval event, not a new publication date. Withdrawn notices and unresolved material updates change dependency validity immediately.

**Implemented interpretation:** source-local extraction and comparison now have strict draft schemas. Exact quotes yield app-computed UTF-8 offsets; absent or repeated quotes reject. Unique non-uploaded selected-asset names are matched locally from quoted mentions; asset IDs and private notes never enter prompts. Unchanged current-model/prompt records can be reused with original lineage. Machine output remains unreviewed, and only the existing human commands can resolve applicability/materiality or approve a plan. Partial URL results are recorded individually, with actual request identity, and do not count as a complete check.

**Recovery diagnostics:** worker failures use a fixed allowlist of safe stage codes. No failure explanation authorizes retry, truncation, budget renewal or approval.
